## Adunarea

Proprietatile adunarii.  
Comutativitatea:  
$a+b=b+a$

Asociativitatea:  
$(a+b)+c = a+(b+c)$


## Scaderea

Scaderea nu este nici comutativa si nici asociativa.

Termenii scaderii:  
$descazut - scazator = diferenta$

| Reguli | Proba scăderii |
| :--- | :--- |
| **Termenii scaderii:** <br> $a-b=c$ | $15-7=8$ |
| **Descazutul se afla prin adunare:** <br> $a=b+c$ | $8+7=15$ |
| **Scazatorul se afla prin scadere:** <br> $b=a-c$ | $15-8=7$ |

In cazul adunarilor si scaderilor, putem considera orice scadere drept **o adunare a opusului**.  
Aceasta este o idee fundamentala in algebra.

**Regula generala este:**  
$\boxed{a-b=a+(-b)}$

Exemplu numeric  
$7-3+5-2$

Putem rescrie:  
$(+7)+(-3)+(+5)+(-2)$

Acum avem **doar operații de adunare**, iar fiecare termen are propriul semn.


## Inmultirea

Termenii inmultirii se numesc $factori$, iar rezultatul se numeste $produs$.

Proprietatile inmultirii .  
Comutativitatea:  
$a*b=b*a$

Asociativitatea:  
$(a*b)*c = a*(b*c)$

{==

Distributivitatea:  
$a*(b+c) = a*b+a*c$  
$a*(b-c) = a*b-a*c$  

==}
!!! note "Nota: Factor comun"

    Inversul distributivitatii este $factorul$ $comun$.  
    Exemplu: $12*7-7$  
    $12*7-7*1=7(12-1)=7*11=77$

<div style="height: 15px;"></div>

Inmultirea a doua paranteze, folosind distributivitatea inmultirii fata de adunare si scadere. 
Avem patru situații posibile:  

1. Plus in ambele paranteze  
$(a+b)(c+d)=ac+ad+bc+bd$

2. Minus in prima paranteza  
$(a-b)(c+d)=ac+ad-bc-bd$

3. Minus in a doua paranteza  
$(a+b)(c-d)=ac-ad+bc-bd$

4. Minus in ambele paranteze  
$(a-b)(c-d)=ac-ad-bc+bd$

Regula generala:  
Fiecare termen din prima paranteza se inmulteste cu fiecare termen din a doua paranteza, tinand cont de semne:

| Inmultire | Semn rezultat |
| :--- | :--- |
| $+ \cdot +$ | $+$ |
| $+ \cdot -$ | $-$ |
| $- \cdot +$ | $-$ |
| $- \cdot -$ | $+$ |
